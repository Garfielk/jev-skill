## Pick a React view, not just a document layout

**Where to use it:** [scenario 77](../../README.md#sc-h28) ·
[中文](../../README.zh.md#sc-h28).

[etweisberg/jev-ui's pinned README](https://github.com/etweisberg/jev-ui/blob/ae38cdae330ec6dd79ea503ffd72fbc7301cd932/README.md)
provides a concrete implementation reference for an existing idea:

- Supply the user's question, available data and view definitions. The example
  distinguishes a time trend from a request for exact row values.
- Its state combines application context, local component data and interaction
  context. Collect only authorized, relevant context; do not upload arbitrary
  analytics or private history just because an interface supports it.
- `Branch` chooses a predefined subtree; `Rank` selects or scores candidates;
  `Gate` adds an optional affordance. The host still renders and acts.
- The author documents one request for judgments in the same render pass.
  Only independent questions belong together; a later answer cannot depend on
  another answer in that request.
- Keep a deterministic fallback and the essential accessible content. A model
  judgment should not be the only way to reach information or an action.

The upstream quick start uses a **server-side TypeSafe key**, not this project's
OpenRouter CLI. It documents live, record, replay and mock modes, including replay
when no key is present. That is the upstream library's behavior, **not** permission
to bypass this project's explicit A/B choice. Its sample threshold is not a
calibration result. The library and this repository's browser-control `jev-ui`
skill happen to share a name; they are separate projects.

**Checked:** the pinned README. **Not checked:** installation, runtime, demo
output, latency or accuracy. The new README prompt is an authored adaptation,
not a captured model answer. The inspected commit is dated September 20 UTC;
that does not establish a project launch date.

## Test fabricated decisions, not just obvious override commands

**Where to use it:** [scenario 10](../../README.md#sc-a11) ·
[中文](../../README.zh.md#sc-a11). Also relevant to the existing
[calibration guidance](../../skills/jev/references/calibration.md).

A [Reddit discussion](https://www.reddit.com/r/pwnhub/comments/1wlu7fj/jev_the_ai_model_that_only_makes_decisions_can_be/)
led to Will Kelly's independent evaluation. We followed it to the author's
[README](https://github.com/willkelly/jev-evaluation/blob/0509cfa03b7545ff73858394e12426bb2d8418f9/README.md),
[E9 report](https://github.com/willkelly/jev-evaluation/blob/0509cfa03b7545ff73858394e12426bb2d8418f9/runs/full-20260919/report.md)
and [prompting guide](https://github.com/willkelly/jev-evaluation/blob/0509cfa03b7545ff73858394e12426bb2d8418f9/PROMPTING.md).

For the author's `jev-1.13.0` ticket-routing setup, the E9 tables report an
attacker-target rate of **0.005 (1/200)** for direct overrides, versus
**0.735 (147/200)** for the authority-claim technique. These are separate
200-ticket conditions, not a universal attack-success rate. They test the
classifier being redirected, **not** the effectiveness of our proposed detector.

**Reusable test:** preserve a clean ticket and its correct route; create paired
variants with explicit redirection, an invented prior managerial decision, and
irrelevant non-instruction text of similar length. Keep the allowed departments
and questions fixed. Record correct/wrong routes, attacker-target selections,
review rate and errors among accepted answers for each condition separately.
Choose review thresholds on development cases, then test on held-out cases.
Do not select a threshold just because the pooled result looks good.

**Checked:** the author's result tables and explanation, not every raw request.
**Not checked:** independent reproduction, deployed-system defenses, or the
compaction-plugin exploit suggested by the Reddit discussion. The inspected
commit is dated September 20 UTC; the author's run directory is named
`full-20260919`. Our existing negative results are unchanged.

relevant existing blocks, source text, verification limits and host-observed
layout descriptions. It recommended enriching existing content for the React
library, evaluation, SkillRanker and Canny; it recommended skipping the proposed
decoration-only change. The host selected **only the first two**: the others
overlap existing tool-routing and evidence-of-completion patterns sufficiently
that another link alone did not justify changing them this round.

one request, no retries; provider-reported cost **$0.000636048**. This is editorial
assistance, not a use-case benchmark or proof that readers will prefer a change.
The receipt preserves the provider response and the input hash; the full working
request is retained locally rather than republishing several upstream READMEs.

original reads, GitHub READMEs and the official OpenRouter Decisions API page.
